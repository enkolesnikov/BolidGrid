# UI-аудит BolidGrid 1.9.0

**Дата:** 14 ноября 2026 г.
**База:** `main`, HEAD `d4ffdf6`, версия 1.8.0.
**Цель:** пройти основные пользовательские сценарии на десктопе, планшете и телефоне, найти и устранить проблемы интерфейса, юзабилити и доступности, не ломая геометрию, сохранность проекта и узнаваемый стиль.

## Методика

- Ручной проход сценариев в реальном Chromium через Playwright: создание/открытие проекта, расстановка приборов, группы, короба, кабели, размеры, спецификация, сохранение/загрузка, экспорт.
- Viewport’ы: **1440×900** (десктоп), **1024×768** (планшет), **390×844** (телефон, touch), дополнительно 360×780 и 412×915 для регрессии.
- Автоматические измерения: горизонтальное переполнение, тап-таргеты меньше 44 px, контраст текста, обрезанный текст, доступность с клавиатуры, ошибки консоли и `pageerror`.
- Скриншоты «до»: [`docs/screenshots/before-desktop-1440.png`](screenshots/before-desktop-1440.png), [`before-desktop-1440-selected.png`](screenshots/before-desktop-1440-selected.png), [`before-tablet-1024.png`](screenshots/before-tablet-1024.png), [`before-mobile-390.png`](screenshots/before-mobile-390.png), [`before-mobile-390-props.png`](screenshots/before-mobile-390-props.png).

### Что уже хорошо

- Точные координаты учитывают все точки отсчёта и ограничиваются стеной.
- Две автоматические размерные линии отменяются одним шагом истории.
- Свободный зазор считается между габаритами, группа не двигается частично.
- Каталог: поиск, фильтры, сворачивание групп, `title` у длинных названий.
- Цвет короба задаётся SVG-атрибутом и не перекрывается CSS.
- Диалог пересечений ведёт к прибору; модальное окно удерживает фокус и закрывается по Escape.
- Selection dock не перекрывает статусбар и нижнюю навигацию; toast не перехватывает касания.
- Печать скрывает интерфейсные панели.

## Круг критики 1: что исправлено

| Замечание | Приоритет | Решение |
|---|---|---|
| Старт трассы короба вне листа давал длину больше стены | P1 | `_channelClick` игнорирует клик вне листа; `Store.addChannel` зажимает точки в стену; тест в smoke |
| Stored XSS через `id` импортированного проекта | P1 | `cleanId` ограничен `[A-Za-z0-9_-]`; ссылки проходят тот же фильтр; тест techdebt |
| Инспектор правил предыдущий одинаковый объект (одинаковый HTML) | P1 | в ключ перерисовки добавлен `selection` (type:id); регрессия в perf |
| Esc во время drag терял undo и оставлял `_before` | P2 | `cancelAll` восстанавливает исходные координаты и очищает снимок; регрессия в perf |
| SVG-экспорт зависел от выделения (terminal-dot) | P2 | терминальные точки исключены из выгрузки; регрессия в perf |
| Стена 0/−1 превращалась в 500×500 | P2 | невалидный размер даёт прежнее значение/умолчание; тест techdebt |
| Landscape 844×390: dock закрывал лист | P1 | dock компактный и прижат вправо, пересечение с листом 0 |
| QA-парсер не видел таблицы в `.table-wrap` | P1 | парсер заходит в обёртку; QA снова 167/167 |
| Превью короба толщиной 16–61 px | P2 | фиксированная экранная толщина 2.5 px |
| В landscape скрыта кнопка «Готово» | P2 | подсказка с кнопкой остаётся в рисующих инструментах |
| «Точно» не прокручивает к координатам | P2 | шторка скроллится к полю X и фокусирует его |
| Печать с легендой, dock и мобильным хромом | P2 | print-CSS скрывает служебные слои, фон белый |
| Стену нельзя переименовать | P2 | кнопка «✎» в списке стен, диалог с ограничением длины |
| 1024 touch: 36 целей <44 px | P2 | `@media (pointer:coarse)` поднимает основные цели до 44 px |
| Мелкие подписи листа на 390 | P2 | кегли подписей и размеров увеличены, заголовок длинной стены сокращается |
| Спецификация: скрытые колонки | P2 | горизонтальный скролл внутри `.table-wrap`; sticky-шапка при этом не сохраняется — известное ограничение |
| Тост накрывает подсказку | P3 | тост поднят над подсказкой на телефоне |
| Каталог: фильтры схлопнулись до 9 px на телефоне | P1 | `.pal-groups{flex:0 0 auto;min-height:44px}`; список 236 px, ~4 прибора на 390 |
