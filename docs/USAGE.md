# Руководство пользователя BolidGrid

Приложение моделирует **стену** (фронтальную проекцию участка монтажа) в реальных
миллиметрах: вдоль стены — координата `X`, по высоте — отметка от уровня пола `0,000`.
На стену ставятся приборы в реальном масштабе, по стене прокладываются короба
(с изменяемым цветом) и проставляются размерные линии.

---

## 1. Проект и стены

| Что | Где |
|---|---|
| Данные объекта, шифр документа, адрес | левая панель «Объект» и кнопка «Свойства проекта…» |
| **Размеры активной стены** | поля «Стена … × … м» в панели инструментов (на телефоне — в меню «⋯») |
| Название стены, новая стена | панель «Стены», кнопка «+ стена» |
| Переключение стен | вкладки над листом или список «Стены» |
| Новый пустой проект | кнопка «Новый проект» (левая панель) |

Стена — это лист с сеткой. Высота стены задаётся в метрах (типовая офисная — 2,7 м).
Устройства не могут выйти за границы листа: координаты ограничиваются автоматически.

## 2. Размещение устройств

1. В левой палитре найдите модель (поиск по названию/марке/заводу).
2. Нажмите на карточку модели — она подсветится, включится режим размещения.
3. Кликните на стене в нужное место — устройство появится и станет выделенным.
4. `Esc` — отмена режима размещения.

На карточке модели справа показано **размещено / по спецификации**
(например `4 / 4`); перерасход выделяется жёлтым.

Перемещение: тяните устройство мышью. Привязка к сетке — 50 мм (отключается
переключателем «Привязка»). Низ устройства притягивается к высоте кабельного канала,
если вы рядом. Несколько устройств перемещаются вместе, если выделены.

Выделение:
- клик — одно устройство;
- `Shift`+клик — добавить/убрать;
- рамка по пустому месту — групповое выделение устройств и каналов.

Свойства устройства (правая вкладка «Свойства»): обозначение (позиция, например `1.1`),
адрес/примечание, модель, координаты `X` и высота, поворот. Габарит показывается по ТД.

Режим размещения **не выключается** после первого прибора: можно поставить несколько подряд,
`Esc` (на телефоне — кнопка «Готово» в подсказке) завершает.

## 3. Кабельные каналы

1. Инструмент **«Канал»** (`C`).
2. Клик — первая точка. Каждая следующая точка автоматически выравнивается
   по горизонтали или вертикали относительно предыдущей.
3. `Enter` или двойной клик — завершить. `Esc` — отменить.

В свойствах канала задаются:
- тип трассы: **Короб DKC 100×40** (по умолчанию, ширина 100 мм), DKC 60×40, DKC 40×25,
  лоток 100, гофротруба Ø20, труба Ø25 — толщина линии равна реальной ширине короба;
- ширина канала в мм (можно менять);
- марка кабеля (список берётся из спецификации);
- подпись (например «КК-1»).

Выделенный канал показывает вершины — их можно тянуть, меняя трассу.
Длина канала считается автоматически и видна в свойствах и кабельном журнале.

### Цвет короба

Два способа:
1. **В панели инструментов** — цветные квадратики справа от «Трасса»: выбранный цвет применяется
   к новым трассам и сразу к выделенному коробу.
2. **В свойствах** — блок «Цвет короба»: палитра или любой свой цвет (пипетка).

После того как вы нарисовали короб, он остаётся выделенным (на телефоне автоматически
открываются «Свойства»), поэтому цвет можно поменять сразу.

## 3a. Размерные линии

1. Инструмент **«Размер»** (`M`).
2. Клик — первая точка, второй клик — вторая. Линия автоматически выравнивается
   по горизонтали или вертикали и подписывается длиной по центру («4 200 мм»).
3. Выделите размер, чтобы тянуть его концы за маркеры или изменить в свойствах:
   координаты X₁/H₁ и X₂/H₂, **текст на линии** (пусто — длина автоматически),
   отступ линии от объекта.
4. `Del` — удалить размер. Размеры сохраняются в проекте и выгружаются в SVG.

Подписи устройств: переключатель **«Подписи»** в панели инструментов — `нет`
(по умолчанию), `кратко` (обозначение), `полные` (обозначение и адрес).
При мелком масштабе подписи скрываются автоматически.

## 5. Спецификация

Вкладка «Спецификация» сопоставляет размещённые устройства с позициями спецификации:

- **По спец.** — количество по документу;
- **Факт** — сколько размещено на стенах;
- **Расхожд.** — зелёный `0`, жёлтый «не хватает», красный «больше, чем нужно».

Для кабеля «Факт» — суммарная длина по марке из ведомости короба и сопоставление
с проектной длиной. Кнопки экспорта: CSV, Markdown, печать.

## 6. Длина короба

Вкладка «Длина короба»: по каждой трассе — стена, тип, длина; внизу — **итог по проекту**
(сколько короба нужно). Экспорт CSV — с разделителем `;` и BOM (открывается в Excel без настроек).

## 7. Печать и экспорт

- **«Печать»** — печатается только лист стены (интерфейс скрывается стилями печати).
  Для PDF выберите «Сохранить как PDF» в диалоге печати.
- **«SVG»** — скачать векторный чертёж листа стены (приборы, короба, размеры)
  для вставки в документацию. `Ctrl`+`S` сохраняет проект в браузере; JSON проекта —
  кнопкой «Экспорт».
- **Импорт** — загрузка проекта из JSON (в том числе сохранённого на другом компьютере).

## 8. С телефона (мобильная версия)

Интерфейс автоматически перестраивается под узкий экран:

- сверху — компактная шапка и панель инструментов (иконки: выбор, канал, панорама, размер, масштаб);
- снизу — таб-бар: **Палитра · Свойства · Спец · Короб**;
- панели открываются нижними шторками; закрыть — крестик, тап по затемнению или повторный тап по вкладке;
- **меню «⋯»** в шапке — удалить, импорт/экспорт, SVG, печать, сохранить, свойства проекта,
  новый проект, демо-проект и переключение стен.

Жесты на листе стены:

| Жест | Действие |
|---|---|
| Тап по устройству | выбрать устройство |
| Тап по пустому месту | снять выделение |
| Удержание (≈0,5 с) по устройству | добавить/убрать из выделения (мультивыбор) |
| Перетаскивание устройства | перенести (привязка к сетке и коробам) |
| Перетаскивание по пустому месту | панорама листа |
| Два пальца | масштаб и панорама одновременно |
| Кнопка «Готово» в подсказке | завершить рисование кабельного канала |

После выбора модели в палитре шторка закрывается сама — сразу тапните по стене, чтобы поставить устройство.

## 9. Сохранение

Проект автоматически сохраняется в браузере (`localStorage`, ключ `bolidgrid:project:v1`)
и восстанавливается при следующем открытии. Чтобы перенести проект на другой компьютер,
используйте «Экспорт» → файл JSON → «Импорт».

«Демо-проект» заменяет текущий проект демонстрационным по спецификации
(текущий проект предварительно выгрузите в JSON, если он нужен).

## Типовой порядок работы

1. Заполнить данные объекта, создать стены нужной длины.
2. Разместить приборы (ППКУП, блоки, АКБ) на стене поста на высоте обслуживания.
3. Разместить оповещатели и другое оборудование по стенам залов/коридоров.
4. Проложить короба: магистраль по верху стены и стояки (цвет — в свойствах трассы).
5. Проставить размерные линии (ширина стены, высота короба, высоты установки).
7. Проверить «Длина короба» — сколько метров нужно; при необходимости выгрузить CSV.
8. Распечатать/сохранить SVG листа для оформления документации.
