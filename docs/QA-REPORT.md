**Дата:** 31 октября 2026 г.

**Объект:** статическая версия редактора из этого дерева проекта.

**Метод:** автоматические браузерные проверки Playwright и визуальный просмотр снимков интерфейса.

## Покрытие

### Редактор

- загрузка демо и спецификации;
- размещение всех видимых моделей, выбор, групповое выделение, удаление и дублирование;
- перетаскивание приборов и ограничение границами стены;
- рисование ортогональных коробов, изменение вершин, участков и всей трассы;
- тип, ширина, цвет и точные координаты трассы;
- создание, редактирование и удаление размерных линий;
- undo/redo, включая повторные и граничные последовательности;
- добавление, переключение, изменение и удаление стен;
- автосохранение и восстановление после перезагрузки;
- экспорт/импорт JSON, валидность SVG, CSV спецификации;
- печатные стили, масштаб и панорама;
- обработка повреждённого импорта и экранирование пользовательского текста.

### Новый сценарий согласования

- X с точками отсчёта «слева», «центр» и «справа»;
- H с точками отсчёта «низ», «центр» и «верх»;
- быстрые высоты низа прибора;
- шесть режимов группового выравнивания;
- равномерное распределение по X и Y;
- временные отступы, их отключение и исключение из SVG;
- постоянные размеры слева и от пола одним действием истории;
- перемещение стрелками на 10 мм и на 1 мм с `Shift`;
- привязка прибора к верхней и нижней кромке короба;
- синхронное изменение высоты горизонтальной трассы;
- точный свободный зазор между двумя и более приборами по X и Y;
- отклонение зазора без частичного перемещения, если группа не помещается;
- обнаружение пересечений «прибор ↔ прибор» и «прибор ↔ короб» с учётом ширины трассы;
- отсутствие замечания при простом касании границ;
- переход из списка замечаний к прибору на листе;
- исключение служебных рамок проверки из SVG;
- закрытие модального окна крестиком и `Escape`.

### Телефон

Проверены viewport’ы **390×844**, **360×780** и **412×915** с сенсорными событиями Chromium:

- отсутствие горизонтального переполнения;
- размеры листа, верхней панели и нижней навигации;
- открытие и закрытие шторок и меню;
- размещение прибора тапом и завершение режима;
- одиночный и групповой выбор;
- снятие выделения по доступной пустой области SVG;
- панорама одним пальцем и pinch-zoom;
- перетаскивание прибора, участка и всего короба;
- свойства, спецификация и ведомость коробов;
- индикатор проверки, диалог замечаний и его закрытие;
- доступность рабочих кнопок при выборе, уведомлениях и серийном размещении.

Дополнительно визуально проверены десктопный инспектор прибора и мобильная шторка свойств: поля не обрезаны, крупные элементы управления доступны, содержимое прокручивается.

## Исправленные дефекты

- Устранена рекурсия в захвате указателя, которая мешала перетаскиванию.
- Исправлены мобильные grid-правила и минимальная ширина контейнеров, вызывавшие расширение viewport и сжатие листа.
- Усилено поведение `hidden` для кнопок и палитры цвета, чтобы CSS `display` не показывал скрытые элементы.
- Учтена компактная карточка выбранного объекта при проверке касания пустого листа.
- Точный ввод от центра прибора округляется до целых миллиметров.
- Имена загружаемых файлов нормализуются в ASCII: браузеры не заменяют файл с кириллическим именем безрасширенным `download`.
- Временные направляющие исключены из экспортируемого SVG.
- Служебные рамки проверки пересечений исключены из экспортируемого SVG.
- Карточка выбора поднята над статусом и скрывается в инструментах размещения/рисования, поэтому не перекрывает «Готово».
- Обычная подсказка скрывается при выборе, но подсказка с рабочей кнопкой остаётся доступной.
- Уведомления больше не перехватывают касания листа на узком экране.
- Модальные окна получили явную кнопку закрытия, управление фокусом и `Escape`.

## Воспроизведение

```bash
npm install
npx playwright install chromium
npm test
npm run test:qa
npm run test:mobile
```

Каждый сьют самостоятельно запускает локальный сервер и возвращает ненулевой код при ошибке. Снимки, загруженные файлы и текстовые результаты создаются в `tests/output/`; каталог исключён из Git.

## Границы проверки

Проверки выполнены в Chromium. Реальные Safari/iOS и Android-браузеры не тестировались на физических устройствах. Печатный макет проверен через print CSS и снимок, но не через физический принтер. Нормативная правильность проекта и актуальность габаритов оборудования остаются предметом инженерной проверки.
