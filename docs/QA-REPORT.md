## Покрытие

### Редактор (`npm test`)

- загрузка демо и спецификации, размещение всех видимых моделей;
- выбор, групповое выделение, удаление, дублирование и перетаскивание с ограничением стеной;
- рисование ортогональных коробов, изменение вершин, участков и всей трассы;
- тип, ширина, цвет и точные координаты трассы; гладкая ПВХ-крышка и стыки секций DKC;
- отсутствие удалённых полей и разделов в спецификации, ведомости, CSV и импортированном JSON;
- создание, редактирование и удаление размерных линий;
- undo/redo, включая повторные и граничные последовательности;
- добавление, переключение, изменение и удаление стен;
- автосохранение и восстановление после перезагрузки;
- экспорт/импорт JSON, валидность SVG, CSV спецификации;
- печатные стили, масштаб и панорама;
- обработка повреждённого импорта и экранирование пользовательского текста.

### Сценарий согласования (`npm run test:qa`)

- X с точками отсчёта «слева», «центр», «справа»; H — «низ», «центр», «верх»;
- быстрые высоты низа, шесть режимов выравнивания, равномерное распределение;
- временные отступы и их исключение из SVG; постоянные размеры одним шагом истории;
- перемещение стрелками на 10 мм и 1 мм с `Shift`;
- привязка к кромке короба, синхронное изменение высоты трассы;
- точный свободный зазор с отказом без частичного перемещения;
- пересечения «прибор ↔ прибор» и «прибор ↔ короб» с учётом ширины; касание границ не считается;
- переход из списка замечаний к прибору, исключение служебных рамок из SVG;
- сохранение/загрузка, две стены, спецификация и ведомость.

### Телефон (`npm run test:mobile`)

Viewport’ы **390×844**, **360×780**, **412×915** с сенсорными событиями:

- отсутствие горизонтального переполнения, размеры листа, шапки и нижней навигации;
- открытие/закрытие шторок и меню, размещение тапом, завершение режима «Готово»;
- одиночный и групповой выбор, снятие выделения по пустой области;
- панорама, pinch-zoom, перетаскивание прибора, участка и всего короба;
- цвет короба через мобильную палитру; свойства, спецификация, ведомость;
- индикатор проверки, диалог замечаний, доступность кнопок при выборе и уведомлениях.

### Доступность (`tests/a11y.mjs`)

- доступные имена кнопок и иконок, живые регионы статуса, тоста и объявлений выбора;
- роль и описание интерактивного SVG-листа;
- связанные `tablist`/`tab`/`tabpanel` для панелей свойств и стен, roving `tabindex`, стрелки;
- `aria-pressed` инструментов и шорткаты `V/C/L/M/H/F`, `Ctrl+Z`/`Ctrl+Y`/`Ctrl+S`;
- видимый контур фокуса, `F1` и `?`, ловушка фокуса, `Escape`, backdrop и возврат фокуса;
- реальный `Tab` по закрытым шторкам на телефоне (`inert`), открытые шторки не выпускают фокус;
- undo/redo в мобильном меню, включая состояния кнопок после отмены;
- защита ввода в полях от глобальных шорткатов, счётчик размеров по активной стене.

### Сенсорные жесты и экспорт (`tests/mobile-touch.mjs`)

- «Вся стена»: ≥88% ширины (390×844), ≥34% площади, масштаб ≥7,5%, пропорции сцены;
- заголовок не обрезан и лист не выдвинут за верх сцены (портрет и альбом);
- тап по прибору 102×107 мм, серия из пяти тапов рядом (5/5), дрожание 4 px не двигает прибор;- попадание по коробу в 10 px и по размерной линии в 8 px;
- undo после перетаскивания, ограничение стеной;
- pinch: приближение, сохранение пропорций, удержание точки под пальцами ≤20 мм, отсутствие прыжка панорамы;
- SVG-экспорт без интерактивных hit-слоёв, цвет короба атрибутом `stroke`.

### Импорт и Store (`tests/techdebt.mjs`, без браузера)

- уникальные `id` при дублях, связи только по существующим приборам и клеммам;
- hostile JSON: `NaN`, `Infinity`, отрицательные координаты, чужая стена, неизвестная модель, огромные строки, XSS-строки в названиях, лимиты коллекций;
- уменьшение стены с прибором, коробом и размером — всё внутри и одним шагом undo;
- защита `id`/`wallId`/`modelId` от патча, clamp координат, лимиты текста;
- `sanitizeSettings`, `loadSaved`, `undo`/`redo`, `uid`, `mm`.

### Производительность (`tests/perf.mjs`)

- `renderAll` на демо и на 106 приборах < 300 мс (факт 1,3 и 3,6 мс);
- `renderFor('project')` на 106 приборах < 50 мс (факт 0,5 мс);
- `renderPalette()` без изменений — no-op и 0 новых узлов DOM;
- состав поиска «2000», скрытые вкладки не рендерятся, спецификация догоняет при открытии;
- сохранение фокуса и каретки в инспекторе;
- строки стен: `role="button"`, `tabindex="0"`, `Enter`/`Space`, кнопка удаления;
- отсутствие `pageerror` и `console.error`.

## Исправленные в 1.9.0 дефекты

- На телефоне не было undo/redo — добавлены пункты меню с корректным неактивным состоянием.
- Закрытые шторки и меню оставались в tab-порядке, `#menu-sheet` показывался вопреки `hidden` — `inert`, `aria-hidden` и реальный `hidden`.
- Вкладки были `role="tab"` без `aria-selected`/`aria-controls` и roving `tabindex`.
- Модальные окна и шторки не удерживали фокус; `Escape` не закрывал мобильные слои.
- Кнопки групп в мобильных свойствах были 27 px, свотчи цвета — 32 px.
- В экспорт SVG попадали `.channel-hit`, `.channel-seg-hit`, `.dev-hit`, `.cable-hit`.
- Pinch-zoom накапливал сдвиг и сплющивал пропорции; «Вся стена» вписывала экспортные поля вместо листа.
- Легенда групп перекрывала заголовок листа на 1024 и телефонe; сцена на 1024 была ~322 px.
- Контраст `.pg-count` (3,74:1) и `.wdel` (4,42:1) был ниже нормы.
- Статусбар считал размеры по всем стенам, а приборы и короба — по активной.
- Список стен был недоступен с клавиатуры.
- Импорт не проверял уникальность `id`, допускал связи на несуществующие приборы и клеммы, пропускал произвольные `settings`/`meta`.
- Уменьшение стены не зажимало концы размерных линий.
- `addDevice`/`updateDevice` позволяли патчем подменить `id`, стену или модель.
- Каталог пересобирал DOM на каждое изменение; скрытые вкладки перерисовывались зря.

## Воспроизведение

```bash
npm install
npx playwright install chromium

npm test
npm run test:qa
npm run test:mobile
node tests/a11y.mjs
node tests/mobile-touch.mjs
node tests/techdebt.mjs
node tests/perf.mjs
```

Каждый браузерный набор самостоятельно поднимает локальный сервер. `techdebt` работает без браузера. Снимки, выгрузки и логи попадают в `tests/output/`; каталог исключён из Git.

## Границы проверки

- Всё выполнено в Chromium (Playwright); реальные Safari/iOS и Android-браузеры на физических устройствах не проверялись.
- Скринридеры NVDA/JAWS/VoiceOver не запускались: проверены ARIA, порядок фокуса и живые регионы, но не озвучивание.
- Контраст подписей внутри SVG-листа автоматически не измерялся.
- Импорт проверен сценариями hostile JSON, без систематического фаззинга.
- Печать проверена через print CSS и снимок, не через физический принтер.
- Нормативная правильность проекта и актуальность каталожных габаритов остаются предметом инженерной проверки.
