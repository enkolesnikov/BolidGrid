- Браузеры кроме headless Chromium (Firefox/Safari/WebView).
- Сборка APK и установка на устройство (в окружении нет Android SDK).
- Систематический фаззинг импорта (только целевые hostile-кейсы).
- Долгие сессии/утечки памяти при тысячах приборов; `findPlacementIssues()` остаётся O(n²).
- Незакоммиченные UX/design-правки поверх HEAD (`main.js`, `store.js`, `wall.js`, `panels.js`, `css/app.css`) полным матриксом не прогонялись — только smoke 103/103.
- **Тестовые пробелы, из-за которых P1/P2 выше прошли зелёными:** нет кейса «два одинаковых объекта → правка выбранного»; нет проверки клампов `updateChannel`/`updateDimension`; нет теста на duplicate у края; нет теста Esc во время drag; нет теста на `null/0` стену; экспорт SVG не проверяется на детерминированность при разном selection.
