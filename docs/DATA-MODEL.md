# Формат проекта BolidGrid

Файл проекта — JSON. Экспорт выполняется кнопкой **«Проект»** или через меню **«⋯ → Экспорт JSON»**. Автосохранение в браузере содержит тот же объект `project`, активную стену и настройки отображения.

```json
{
  "app": "BolidGrid",
  "schema": 1,
  "project": {
    "version": 1,
    "meta": {
      "name": "ДФО .... СПС и СОУЭ — г. Елизово",
      "object": "…",
      "address": "г. Елизово, ул. Ленина, д.15а",
      "contractor": "ООО «РитейлСтройСервис»",
      "doc": "ДФО .... СПС.СОУЭ"
    },
    "walls": [
      {
        "id": "wall_x1",
        "name": "Стена 1 — пожарный пост",
        "width": 4200,
        "height": 2700
      }
    ],
    "devices": [
      {
        "id": "dev_x1",
        "modelId": "sirius",
        "wallId": "wall_x1",
        "x": 300,
        "y": 1300,
        "rot": 0,
        "tag": "1.1",
        "address": "",
        "note": ""
      }
    ],
    "channels": [
      {
        "id": "ch_x1",
        "wallId": "wall_x1",
        "kind": "кабель-канал",
        "width": 100,
        "points": [[120, 2450], [4080, 2450]],
        "cableModelId": "КПСнг(А)-FRHF 1x2x0,75",
        "color": "#94a3b8"
      }
    ],
    "dimensions": [
      {
        "id": "dim_x1",
        "wallId": "wall_x1",
        "a": [0, 1300],
        "b": [300, 1300],
        "text": "",
        "offset": -55
      }
    ]
  }
}
```

## Система координат

- Единицы всех координат и габаритов — **миллиметры**.
- `walls[].width` и `walls[].height` — длина и высота стены.
- `devices[].x` — координата левой грани прибора от левого края стены.
- `devices[].y` — высота **нижней грани** прибора от пола.
- Габариты берутся из `js/catalog.js` (`w`, `h`), а не дублируются в файле проекта.
- `channels[].points` — массив точек `[x, высота_от_пола]`, минимум две точки.
- `dimensions[].a` и `dimensions[].b` — концы размерной линии в той же системе координат.
- В SVG ось Y направлена вниз, поэтому экранная координата вычисляется как `wall.height - y`.

## Поля объектов

| Поле | Назначение |
|---|---|
| `devices[].modelId` | Идентификатор модели из каталога |
| `devices[].rot` | Поворот: 0, 90, 180 или 270° |
| `devices[].tag` | Рабочее обозначение на листе |
| `devices[].address` | Необязательный адрес или дополнительная подпись |
| `channels[].kind` | Тип трассы |
| `channels[].width` | Ширина короба/трубы в миллиметрах |
| `channels[].cableModelId` | Марка кабеля из спецификации или пустая строка |
| `channels[].color` | HEX-цвет; пустая строка означает цвет по типу |
| `dimensions[].text` | Подпись; пустая строка включает автоматическую длину |
| `dimensions[].offset` | Отступ размерной линии; допускаются отрицательные значения |

Видимые идентификаторы моделей: `sirius`, `sp2`, `sp4_220`, `ar2`, `kdl`, `sp1`, `s2000m`, `rip12`, `bp12`, `switch`, `socket`, `custom`.

Типы трасс: `кабель-канал`, `короб-60`, `короб-40`, `лоток`, `гофра`, `труба`.

## Соответствие спецификации

Поле `specPos` в каталоге связывает модель с номером позиции `data/spec.json`. Сопоставление «по спецификации / фактически» выполняется по этому номеру, поэтому отображаемое имя модели можно менять без изменения расчёта.

Фактическая длина кабеля вычисляется по геометрии трасс с соответствующей `cableModelId`, суммируется в миллиметрах и показывается в метрах.

## Нормализация и совместимость

Текущая версия схемы — `1`. При импорте:

- отсутствующие или некорректные стены заменяются стеной по умолчанию;
- приборы ограничиваются габаритами своей стены;
- скрытые модели пропускаются, неизвестные модели заменяются на `custom`;
- неизвестные типы трасс заменяются на `кабель-канал`;
- диагональные участки преобразуются в горизонтальные или вертикальные;
- размеры и координаты ограничиваются стеной;
- неизвестные поля игнорируются.

Временные отступы выбранного прибора, умные направляющие и результаты проверки пересечений не входят в JSON: они каждый раз строятся редактором заново. Проверка `findPlacementIssues()` использует текущие габариты каталога и ширину трасс, поэтому её результат не требует отдельной миграции данных.
